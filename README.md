# ✨ 100 Things About You

### A Cinematic Python Typography Animation

A beautiful visual experience built with **Python and Pygame**, featuring 100 thoughtful statements brought to life through elegant typography, glowing golden highlights, flowing text layers, and cinematic lighting effects.

This project transforms meaningful words into an immersive full-screen animation.

---

## 🌟 Project Preview

**100 Things About You** is a creative Python animation that displays 100 unique statements celebrating the little things that make someone special.

Each statement appears in the centre of the screen with smooth transitions, while other statements flow horizontally across the background.

The animation creates a premium cinematic atmosphere using a midnight navy and antique gold colour palette.

---

## 🎨 Features

- **100 Unique Statements:** A collection of 100 thoughtful and meaningful messages.
- **Kinetic Typography:** Smoothly animated text with elegant transitions.
- **Golden Highlights:** Important keywords are highlighted with glowing gold typography.
- **Dynamic Background:** A cinematic midnight navy gradient.
- **Flowing Text Layers:** Multiple horizontal text layers moving at different speeds and directions.
- **Ambient Lighting:** Soft golden light, continuous light sweeps and subtle glowing effects.
- **Atmospheric Particles:** Tiny floating particles and subtle visual grain.
- **Animated Progress Bar:** Tracks the number of statements displayed.
- **Automatic Playback:** All 100 statements appear automatically.
- **No External Assets:** Backgrounds, lighting effects and visual elements are generated directly using Python.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/100-things-about-you.git
```

### 2. Navigate to the project folder

```bash
cd 100-things-about-you
```

### 3. Install the dependencies

```bash
pip install -r requirements.txt
```

Alternatively:

```bash
pip install pygame
```

### 4. Run the animation

```bash
python 100_things_about_you.py
```

## 💡 How It Works

The animation uses Pygame to create a complete visual scene.

1. **Background Generation:** A custom midnight gradient creates the cinematic atmosphere.
2. **Text Rendering:** Statements are rendered with different font styles and highlighted keywords.
3. **Scrolling Layers:** Multiple rows of text move horizontally in different directions.
4. **Featured Statements:** Each statement appears individually in the centre with smooth fade and scaling effects.
5. **Lighting Effects:** Golden light sweeps, subtle glows and moving light trails add depth.
6. **Progress Tracking:** An animated progress indicator follows the number of statements displayed.
